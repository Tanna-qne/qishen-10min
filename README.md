# 起身十分钟

久坐一小时后的 10 分钟锻炼。每轮按「热身 → 肩颈 → 下肢 → 推 → 拳击 → 肩颈 → 拉 → 拳击 → 肩颈 → 腿部冲刺」随机抽取 10 个动作，每个 50 秒加 10 秒准备，尽量避开最近两轮做过的动作。

- 器材：徒手、两个哑铃、一根单杠（可在页面里关掉哑铃或单杠）
- 全程不跳、不用趴地上，适合隔音不好的房间
- 重点放松肩颈，每轮最后用高强度腿部动作冲刺
- 火柴人动画示范、倒计时、中文语音提示、每天完成次数（只存在本机浏览器）

在线使用：https://tanna-qne.github.io/qishen-10min/

直接用浏览器打开 `index.html` 也能用。

## 动作库（53 个核心动作）

- `index.html` 里的 `LIB`：36 个火柴人动画，包括哑铃、单杠动作、9 个徒手拳击连招和 6 个腿部冲刺动作
- `desk3d.js`：17 个 3D 木头人动画，以肩颈放松为主。模型和动画在 `3d/`，来自 [desk-break](https://github.com/shlomorsh/desk-break)（MIT 许可，见 `3d/LICENSE`）

不喜欢某个动作：删掉对应的一整块 `{ ... }` 即可。每个分类最好留 3 个以上，不然每轮会重复。
